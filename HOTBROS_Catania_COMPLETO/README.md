# HOTBROS Catania — Flask
Menu completo basato sul listing pubblico HotBros consultato a settembre 2026.
Categorie incluse: VEG BROS, COMBO MENU', STARTERS, FRIED CHICKEN, HOTDOG, URBUNS, GLUTEN FREE, SALSE, DRINK, PLANT BASED NUGGETS.
Build Render: `pip install -r requirements.txt`
Start Render: `gunicorn app:app`
Le immagini sono richiamate dai CDN pubblici del listing Glovo; per un uso commerciale definitivo verifica i diritti di utilizzo e sostituisci gli asset se necessario.
